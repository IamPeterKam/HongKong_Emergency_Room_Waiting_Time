## 📊 資料來源說明（重要）

本應用程式所顯示之急症室等候時間資料，來源自香港政府所提供的公開數據：

- **資料集名稱**：急症室等候時間  
- **資料提供單位**：醫院管理局  
- **資料平台**：香港政府開放數據平台（data.gov.hk）  
- **官方資料集連結**：  
  https://data.gov.hk/tc-data/dataset/hospital-hadata-ae-waiting-time

本應用程式及本支援網站：

- 僅作為公開資料的 **整理與展示工具**
- 不會修改、詮釋、推論或延伸任何臨床或醫療意義
- 不對資料的準確性、即時性或完整性作出任何保證

實際資訊應以資料發布單位之官方公布為準。
